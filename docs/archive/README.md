# RouteDeck Documentation Archive

Everything below this directory is historical. It is retained for provenance,
design rationale, completed implementation records, or run evidence. It is not
current implementation guidance and must not override `critical_prompt.md`, the
accepted ADR chain, `docs/route-deck-reference.md`, or the live architecture
maps.

Archived commands, paths, names, and status statements may describe the source
tree as it existed when the document was written.

## Contents

| Location | Classification |
| --- | --- |
| `superpowers/plans/` | Completed or superseded implementation plans. |
| `superpowers/specs/` | Implemented or superseded design records. |
| `concepts/` | Earlier framework/product concepts replaced by the current reference. |
| `reference-apps/` | Retired product reference-app proposals. |
| `reports/` | Point-in-time validation reports. |
| `handoffs/` | Completed restart/planning handoffs. |
| `whitepaper/` | Earlier narrative material preserved in source and rendered forms. |

See `architecture/documentation-map.md` for the current authority order.
