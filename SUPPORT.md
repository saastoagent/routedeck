# RouteDeck Support

RouteDeck is alpha software and currently has no commercial support or response
SLA.

- Use GitHub Issues for reproducible bugs and focused feature proposals.
- Use repository documentation and the Medusa reference consumer for setup and
  architectural examples.
- Use the private process in [`SECURITY.md`](SECURITY.md) for vulnerabilities;
  never disclose them in a public support request.

Include versions, runtime location, exact commands, expected and actual
behavior, and the smallest safe reproduction. Do not include credentials,
private user data, demo database contents, or unsanitized traces.
