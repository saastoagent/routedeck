conversation ownership follows ADR-006; non-superseded structure follows
ADR-005; scope and local execution follow ADR-004.

comma-separated, project-relative, and describe live source or maintained
documentation. Archive/history paths are ownership evidence, not current

## Closeout Rule

For each changed live source file, name the owning row and either update its
architecture/test anchors or state why those contracts remain correct. Archive
and generated output never replace source-level proof. Cross-owner behavior
must also appear once in a verified implementation crosswalk so file mapping is
not mistaken for semantic contract coverage.
