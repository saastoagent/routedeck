# RouteDeck Code Map

Last updated: 2026-07-12

This is the canonical subsystem-to-code map. Active authority follows
[ADR-004](../decisions/ADR-004-routedeck-medusa-consumer-driven-runtime.md),
[ADR-005](../decisions/ADR-005-operation-centric-state-and-consumer-structure.md),

[implementation plan](../docs/superpowers/plans/2026-07-11-routedeck-medusa-agent-implementation.md).
Runtime and release verification are local Windows work; no remote runtime is
part of this architecture.

## How To Use This Map

- Start here before moving an interface across a package boundary.
- Keep the owning row's source globs, public interfaces, docs, and tests aligned.
- Run `python scripts/check_doc_coverage.py` as an advisory closeout check.
- Do not infer a release result from this map. Release evidence is produced by
  the release verifier for a specific run.

The `Source globs` column is parsed by `scripts/check_doc_coverage.py`; globs are
comma-separated and relative to this project root.

## Closeout Rule

For each changed source file, name the owning row and either update its docs and
test anchors or state why they remain correct. Generated output and release
evidence never replace source-level tests or a real-source-of-truth smoke.
