# Security Policy

## Supported Versions

RouteDeck is pre-1.0 alpha software. Until the first public release, only the
current default branch is eligible for security fixes. After releases begin,
support status will be listed here explicitly; no support for older versions
should be inferred.

## Reporting a Vulnerability

Do not open a public issue for a suspected vulnerability. Use GitHub's private
vulnerability-reporting form:

https://github.com/saastoagent/routedeck/security/advisories/new

Include affected components and versions, reproduction steps, impact, and any
suggested mitigation. Do not include real credentials or third-party user
data. Maintainers will acknowledge the report when it is reviewed, but this
alpha project does not yet promise a response or remediation SLA.

Public issues may be used for hardening ideas that do not disclose an active
vulnerability.
