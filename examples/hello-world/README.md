# RouteDeck Hello World

This is the zero-API-key first-success example used by the
[RouteDeck wiki](../../wiki/Hello-World.md). It compiles one feature-owned node
and validates its exact implementation bindings.

From the repository root, after installing the source package:

```powershell
python .\examples\hello-world\hello_world.py
```

Expected output:

```text
RouteDeck application: hello-world
Entry node: hello.home
Route: /
Nodes: hello.home
```

The example is intentionally not a production runtime. Continue with the
[wiki learning path](../../wiki/Home.md) to add operations, persistence,
transport, conversation, and browser integration.
